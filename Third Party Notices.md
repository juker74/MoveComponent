# Third-party dependencies

This repository contains the MoveComponent sources exported from GameFrameX.Unity, whose repository license is retained in LICENSE.md. Existing namespaces, assembly identities and script GUIDs are preserved.

NodeCanvas / ParadoxNotion CanvasCore, SimpleJSON, GameFrameX packages, Unity UGUI, TextMeshPro and Test Framework are external dependencies; their sources are not copied into this repository and remain under their respective licenses. See Documentation~/Dependencies.md and dependency-sources.json for sources and tested versions. The NodeCanvas installation used for validation reports CanvasCore FRAMEWORK_VERSION = 3.30.
