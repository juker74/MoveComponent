# Chapter catalog editor

Approved scope (2026-11-11): one ComposerGraph per chapter, with an editor-only catalog asset and Inspector. Implement editing and JSON import/export first; do not implement chapter execution, cross-chapter variables, or chapter-end/jump nodes in this change.

The catalog stores a start chapter ID and an ordered list of entries. Each editor entry stores a stable generated chapter ID, display name, ComposerGraph reference, and entry node document ID. Renaming/reordering retains IDs. Entry selection shows labels but stores document IDs; changing graphs clears the entry. The Inspector supports add/remove/reorder, opening graphs, choosing the start chapter, validation, importing, and exporting.

Runtime receives only serializable catalog documents and a strict JSON codec, under the VideoNodes extension. No UnityEditor/NodeCanvas references enter runtime assemblies. JSON fields are schemaVersion, startChapterId, and chapters; each chapter has chapterId, name, graphKey, entryNodeId. Export uses chapters/<chapterId>.json and catalog.json; IDs must be safe path segments and unique (also across case insensitive filesystems). Chapter order is significant. Graph IDs must be unique within one catalog. Each entry must point at an existing executable video/control node, not a pure data cell.

Reuse ComposerGraphAdapter and GraphJsonCodec for graph conversion and structural validation, plus VideoFlowLoader for video-flow business validation. Catalog validation reports actionable per-chapter errors. A dedicated export destination is published as one directory batch only after all content validates and encodes. Failed export leaves an existing destination intact. Do not overwrite unrelated directories or the Unity project.

Import reads a catalog.json and its relative graph keys from the selected bundle. Reject traversal, rooted paths, symlink escape, malformed/oversize files, invalid graphs and missing entries before creating assets. Import creates a fresh catalog and graph assets in a new Assets subfolder; on failure clean only assets created by that operation. Existing assets are never silently overwritten. Preserve chapter, graph and node identities and order on round-trip. Support Undo for normal Inspector edits through SerializedObject.

Deliver in the existing MoveComponent UPM package, retaining plugin files and metadata. Verify strict JSON, round-trip identities/ordering, entry validation, failed export preservation, malformed import with no partial assets, and package structure; run existing EditMode tests and new chapter tests in Unity 2022.3.62f3.
